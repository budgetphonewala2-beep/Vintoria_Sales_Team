# Truth rules — every sentence must trace to evidence

A single invented client, metric, tool or promise destroys the deal and can break consumer-protection law. These
rules apply to every VINTORIA skill, every draft, every proposal and every call note.

## Evidence tiers

| Tier | Trusted for claims | Examples |
|---|---|---|
| **tool** | Yes | Page fetches you performed, saved screenshots, audit facts you verified live |
| **catalog** | Yes | The 270-service catalog and the discipline files in `references/services/` |
| **profile** | Yes | `workspace/profile/SELLER-PROFILE.md`: case studies, clients, years, pricing, delivery, guarantees |
| **prospect** | Yes | The buyer's own post, site copy, job ad, reply text |
| **seller-note** | No | Anything you wrote earlier: dossiers, research notes, drafts, proposals, call notes |
| **memory** | No | What you think you know about a company or industry |
| **snippet** | No | A search-result snippet on its own; open the page and verify first |

## Allowed vs forbidden

**Allowed**
- A fact you observed on a page the prospect controls, quoted or paraphrased precisely.
- A service you sell, named exactly from the catalog.
- A number you measured yourself in this session (page weight via your tools, count of H1s, missing viewport).
- A consequence, clearly hedged: "so phone visitors may see the desktop layout".
- A missing proof point, visibly marked: `[ADD REAL CUSTOMER RESULT]`.
- A missing price, visibly marked: `[PRICE TO CONFIRM]` / `[TO CONFIRM: timeline]`.
- A question.

**Forbidden**
- Invented clients, logos, awards, team members, locations, integrations, tools or partnerships.
- Invented metrics ("we increased conversion 40%"), industry stats ("studies show 70%…"), or averages.
- Promises or guarantees ("page one in 30 days", "double your sales").
- Flipping a fact ("your site has a viewport tag" when the audit found none).
- Presenting a guess as verified (email, title, company size, revenue, tech stack).
- Saying something was sent, booked, verified, scanned or delivered when it was not.
- Quoting a price, discount or delivery date from anywhere except the seller profile.
- Using another prospect's facts for this prospect.

## Writing when you don't know

| Situation | Write |
|---|---|
| Unknown fact in research | `Not found` |
| Unknown fact in outreach | leave it out |
| Likely consequence | hedge: "may", "looks like", "from the page alone" |
| Missing result/proof | `[ADD REAL CUSTOMER RESULT]` |
| Missing price/timeline | `[PRICE TO CONFIRM]`, `[TO CONFIRM: …]` |
| Two sources disagree | say so, prefer the page the prospect controls |

## Self-check before anyone sees a draft

1. Underline every declarative sentence. For each one, name the file or page that supports it.
2. Any sentence you cannot support: delete it or turn it into a question.
3. Every proper noun (client, brand, person, place, tool) must appear in the same evidence you used for the claim.
4. Every number must appear in one single source, with the same unit.
5. Quotes must be word-for-word.
6. No `[PLACEHOLDER]` except the approved markers above, and each one must be visible to the seller.

If a draft fails, fix the draft — never lower the standard.
