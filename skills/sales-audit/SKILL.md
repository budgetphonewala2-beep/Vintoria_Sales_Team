# Website Audit — proof-of-work facts for outreach

A specific, true observation about someone's own website is the strongest opener an agency has.
This skill produces only facts the page itself proves, so outreach built on it survives the claim check.

## Before you start

1. **Scripts.** `<SCRIPTS>` is the `scripts/` folder of the `sales` skill (`../sales/scripts/` next to this skill's
   folder). Run them with `python` (Windows) or `python3` (macOS/Linux). Each prints one JSON object — treat it as
   evidence to check, not as truth.
2. **The seller.** Read `SELLER-PROFILE.json` if it exists (`python <SCRIPTS>/seller_profile.py show`). If it doesn't,
   carry on with what the user told you and suggest `sales-setup` at the end — don't block urgent work on it.
3. **The prospect.** Everything about one prospect lives in `prospects/<slug>/` — slug = their domain (`acme.com`), or
   `name@platform` (`anita-desai@linkedin`) for a lead without a website. `python <SCRIPTS>/pipeline.py find <email|name|domain>`
   finds it. Never use one prospect's facts for another.
4. **The pipeline.** `~/.ai-sales-team/pipeline.db` is shared by every agent and session. Before you finish, write
   what you learned (stage, note, next action, attached file) — the next agent only sees what the pipeline shows.
5. **Web access.** Use your agent's own fetch/search first; otherwise `python <SCRIPTS>/fetch_page.py <url> ...` and
   `python <SCRIPTS>/web_search.py "<query>"`; with `APIFY_TOKEN`, `python <SCRIPTS>/lead_sources.py`. If you can't fetch
   something, write "Not found".
6. **Facts only.** Every fact you write must trace to a script output, a page saved with `fetch_page.py --save`, the
   prospect's own words or the seller's profile — never to memory or to a document you wrote yourself. Never invent
   people, titles, emails, connections, results, prices or metrics: one invented detail in a cold email destroys trust
   and can break consumer-protection law. Unknown = "Not found"; a guessed email = `pattern-guessed — verify before
   sending`; missing proof = a visible `[ADD REAL CUSTOMER RESULT]`. Never say something was sent, booked, verified or
   scanned unless a script's output says so. The guards: `../sales/references/truth-rules.md`.

## Steps

1. Run the audit and save it in the prospect folder:
   `python <SCRIPTS>/site_audit.py --url <url> --save prospects/<slug>/SITE-AUDIT.json`
   (add `--no-links` for a faster run, `--pagespeed` for Google PageSpeed Insights: Google's own mobile score, LCP,
   layout shift and the real-user Chrome UX verdict — the most persuasive facts for slow sites; robots.txt is respected). For the full picture in one run — audit plus
   company, people, email and web research with ranked hooks — use `python <SCRIPTS>/prospect_scan.py <url>` instead.
2. Write `prospects/<slug>/SITE-AUDIT.md`: the URL, date, and a table of every fact (`statement` + `evidence`).
3. Pick the **top 3 observations** that matter to the prospect's business, using
   `references/fact-to-hook.md` (e.g. no viewport → phone visitors get the desktop layout; no CTA →
   visitors don't know the next step; copyright 2019 → site looks unmaintained). State the fact exactly as the
   audit does; any consequence you add must be phrased as likely ("so phone visitors probably..."), never as a
   measured number.
4. Record it: `python <SCRIPTS>/pipeline.py add --url <url>` (if new), `python <SCRIPTS>/pipeline.py attach <slug> prospects/<slug>/SITE-AUDIT.json --kind site-audit`,
   `python <SCRIPTS>/pipeline.py note <slug> "Audit hooks: <hook 1>; <hook 2>"`.
5. **Local comparison** (local businesses, powerful hook): `python <SCRIPTS>/lead_sources.py maps --search "<category> in <area>" --max 10`
   and compare rating, reviews and website with the top 3 nearby competitors — "3 of the 5 top-rated dentists in
   Koregaon Park have online booking; yours doesn't" is a fact if the data shows it.
6. Suggest `sales-outreach` next — it will use these facts as evidence.

## Rules
- Facts only. No scores like "your SEO is 4/10", no guessed traffic, no "your site is slow" unless the fact
  says the download took N seconds — and then quote N.
- Never claim certificate or security problems from a TLS error on your side.
- If the homepage didn't load or robots.txt blocks it, say so and stop.
