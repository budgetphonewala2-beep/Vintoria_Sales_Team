# Intent Hunt — find people asking for what you sell

Intent beats cold lists: a person who wrote "need a website for my clinic" this week is worth fifty
cold contacts. This skill finds those posts, separates real buyers from noise, and puts them in the pipeline.

## Before you start

1. **Scripts.** `<SCRIPTS>` is the `scripts/` folder of the `sales` skill (`../sales/scripts/` next to this skill's
   folder). Run them with `python` (Windows) or `python3` (macOS/Linux). Each prints one JSON object — treat it as
   evidence to check, not as truth.
2. **The seller.** Run `python <SCRIPTS>/seller_profile.py check`. This skill builds its queries, emails or prices
   from `SELLER-PROFILE.json`, so if it isn't `Ready.` run the `sales-setup` interview first (when the user is in a
   hurry, ask just the missing required questions in one message and save the answers with `seller_profile.py set`).
3. **The prospect.** Everything about one prospect lives in `prospects/<slug>/` — slug = their domain (`acme.com`), or
   `name@platform` (`anita-desai@linkedin`) for a lead without a website. `python <SCRIPTS>/pipeline.py find <email|name|domain>`
   finds it. Never use one prospect's facts for another.
4. **The pipeline.** `~/.ai-sales-team/pipeline.db` is shared by every agent and session. Before you finish, write
   what you learned (stage, note, next action, attached file) — the next agent only sees what the pipeline shows.
5. **Web access.** Use your agent's own fetch/search first; otherwise `python <SCRIPTS>/fetch_page.py <url> ...` and
   `python <SCRIPTS>/web_search.py "<query>"`; with `APIFY_TOKEN`, `python <SCRIPTS>/lead_sources.py`. If you can't fetch
   something, write "Not found".
6. **Facts only.** Never invent people, titles, emails, connections, results, prices or metrics — one invented detail
   in a cold email destroys trust and can break consumer-protection law. Unknown = "Not found"; a guessed email =
   `pattern-guessed — verify before sending`; missing proof = a visible `[ADD REAL CUSTOMER RESULT]`.

## Steps

1. **Know the seller.** `python <SCRIPTS>/seller_profile.py check` — if the profile is missing or incomplete, run `sales-setup` first. The
   queries are generated from it (niches, platforms, pains, triggers, tools clients leave, buyer titles,
   countries, excluded markets): preview them with `python <SCRIPTS>/query_library.py`. Read `references/queries.md` for the formula.
2. **Collect leads** with what the user has (details for every source: `references/queries.md`):
   | They have | Run | Gives |
   |---|---|---|
   | `APIFY_TOKEN` | `python <SCRIPTS>/lead_sources.py hunt --posted week --max 30 --save hunt.json` | LinkedIn posts, Hacker News, Reddit, X, Google X-ray — people asking now |
   | `APOLLO_API_KEY` or an Apollo connector in your agent | `python <SCRIPTS>/lead_sources.py apollo-api --max 100` (or the connector's people search with the profile's titles, countries, size, niches) | decision-maker lists (no intent) |
   | `APIFY_TOKEN`, no Apollo key | `python <SCRIPTS>/lead_sources.py apollo` / `python <SCRIPTS>/lead_sources.py leads` / `python <SCRIPTS>/lead_sources.py people` (+ `--add --verify`) | the same lists via Apify |
   | a local niche (dentists, restaurants…) | `python <SCRIPTS>/lead_sources.py maps --add` | businesses with no site / poor reviews + phone |
   | nothing | `python <SCRIPTS>/lead_sources.py hackernews` (free) and `python <SCRIPTS>/lead_sources.py reddit` (free JSON, may be rate-limited); for the rest run the queries from `python <SCRIPTS>/query_library.py` in your own web search, save posts as JSON lines (`url`, `text`, `author`) and score them with `python <SCRIPTS>/intent_scan.py --file posts.jsonl --save hunt.json` | |
   Before the first paid run, tell the user the ceiling (`APIFY_MAX_USD` per run × `APIFY_MAX_RUNS`, default $1 × 8)
   and afterwards what ran (`sources_run`, `by_source`, `kept_by_source`, `excluded_market`). Leads arrive
   de-duplicated; sellers, job ads and job seekers are already filtered out. A candidate with `contact_in_post`
   already has an email/phone from the post — use it, don't pay a finder for it.
3. **Judge every candidate** with `references/intent-rubric.md`. For each, decide: buyer / seller /
   job_seeker / other, services wanted, urgency, budget (only if stated), location/timezone (only if stated
   or obvious), and an **exact quote** from the post that proves intent. Discard anything below confidence 0.6.
4. **Score buyers**: write their signals to a JSON file and run
   `python <SCRIPTS>/lead_scorer.py --mode agency signals.json` (fields: `intent_confidence`, `urgency`,
   `posted_days_ago`, `comments`, `budget_stated`, `services_requested`, `services_offered`, `email_status`,
   `sources_count`).
5. **Add to the pipeline** (one per buyer) — their own website if the post or profile names one, else the post URL
   with the person's name (it becomes `name@platform`, e.g. `anita-desai@linkedin`, so leads never merge):
   `python <SCRIPTS>/pipeline.py add --url <their site, or the post URL> --name "<person or company>" --source <source>:<query-id>`
   `python <SCRIPTS>/pipeline.py score <slug> <score>` · `python <SCRIPTS>/pipeline.py note <slug> "Post: <url> — quote: '<exact quote>'"`
6. **Deep-scan the top buyers** (best 5-10, freshest first):
   `python <SCRIPTS>/prospect_scan.py <their site or domain> --post-text "<post>" --post-url <url> [--first X --last Y] --source hunt:<query-id>`
   → `prospects/<slug>/DOSSIER.md` with the audit, people, the best email (finders skipped when the post or site
   already has one), web research and ranked hooks; the prospect and contact go into the pipeline. No website?
   `python <SCRIPTS>/find_email.py --text "<post text>"` and record with `python <SCRIPTS>/pipeline.py contact ...`.
   No verified email? Suggest the user reply publicly under the post or DM from their own account — give
   them a 2-line message. Never post or DM on their behalf.
7. **Report**: a table — buyer, platform, what they need, exact quote, posted, score, contact status, next step.
   Respond to fresh asks (under 48 h) the same day: an email if there is a verified address, otherwise a
   2-line public reply or DM for the user to post from their own account.

## Rules
- The quote must be copied exactly from the post. No quote = not a buyer.
- Agencies advertising, freelancers offering services, "#hiring" job posts and job seekers are never buyers.
- Respect each platform's terms: only public posts, no scraping behind logins, no automated messaging.
- Paid search calls are capped by `--max-calls`; tell the user how many calls a run used.
- Speed beats polish on intent leads: most asks get answered within a day or two by someone.
