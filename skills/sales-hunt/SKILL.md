# Intent Hunt — find people asking for what you sell

Intent beats cold lists: a person who wrote "need a website for my clinic" this week is worth fifty
cold contacts. This skill finds those posts, separates real buyers from noise, and puts them in the pipeline.

## Before you start

1. **Scripts.** `<SCRIPTS>` means the `scripts/` folder of the `sales` skill — `../sales/scripts/` next to this
   skill's folder. Run them with `python` (Windows) or `python3` (macOS/Linux). Every script prints one JSON
   object. Script output is evidence to check, not truth.
2. **Web access.** Use your agent's own web fetch / search if it has them. Otherwise run
   `python <SCRIPTS>/fetch_page.py <url> [<url> ...]` and `python <SCRIPTS>/web_search.py "<query>"`
   (search needs `BRIGHTDATA_API_KEY`); with `APIFY_TOKEN`, `python <SCRIPTS>/lead_sources.py` searches LinkedIn
   posts, Google and Reddit. If you can't fetch something, write "Not found" — never fill gaps.
3. **Prospect folder.** Files about one prospect live in `prospects/<slug>/` (slug = domain without `www.`,
   e.g. `acme.com`). Given only a name, look for an existing `prospects/*/` folder first, then find the
   official domain. Never use another prospect's files as context. Shared files (`IDEAL-CUSTOMER-PROFILE.md`,
   `OBJECTION-PLAYBOOK.md`, `SALES-REPORT*`) stay in the working-directory root.
4. **Pipeline.** The pipeline database (`~/.ai-sales-team/pipeline.db`) is the source of truth across
   sessions and agents. Record what you learn with `python <SCRIPTS>/pipeline.py ...` (commands below).
5. **Know the seller first.** Run `python <SCRIPTS>/seller_profile.py check`. If the profile is missing or not
   `Ready.`, stop and run the `sales-setup` interview before anything else — every query, filter, email,
   proposal and send time is built from `SELLER-PROFILE.json`. Then read `IDEAL-CUSTOMER-PROFILE.md` if it exists.
   For service sellers (agency, freelancer, consultant) judge fit by visible need — site quality, public posts
   asking for help, hiring for the role, ad activity — not by funding or headcount.
6. **Facts, not fiction.** Never invent people, titles, emails, mutual connections, customer results,
   funding or metrics. Unknown = "Not found". Pattern-built emails = `pattern-guessed — verify before
   sending`. A missing proof point = a visible `[ADD REAL CUSTOMER RESULT]` marker.

## Steps

1. **Know the seller.** `python <SCRIPTS>/seller_profile.py check` — if the profile is missing or incomplete, run `sales-setup` first. The
   queries are generated from it (niches, platforms, pains, triggers, tools clients leave, buyer titles,
   countries, excluded markets): preview them with `python <SCRIPTS>/query_library.py`. Read `references/queries.md` for the formula.
2. **Collect posts** — any of these (best first):
   - Everything at once: `python <SCRIPTS>/lead_sources.py hunt --posted week --max 30 --save hunt.json` (profile-driven; leads from excluded
     markets are dropped and counted in `excluded_market`)
     (Hacker News free; LinkedIn, Reddit, X, Google X-ray with `APIFY_TOKEN`). Or one source:
     `python <SCRIPTS>/lead_sources.py linkedin` · `python <SCRIPTS>/lead_sources.py hackernews` (incl. the monthly "Seeking freelancer" thread) · `python <SCRIPTS>/lead_sources.py reddit`
     (r/forhire [Hiring] and more; free JSON without Apify) · `python <SCRIPTS>/lead_sources.py x` · `python <SCRIPTS>/lead_sources.py facebook --group-url <public group>`
     · `python <SCRIPTS>/lead_sources.py google` — each uses the profile, or `--services/--location`, or your own `--query` (repeatable).
   - **People databases** (decision makers matching the profile — lists, no intent): `python <SCRIPTS>/lead_sources.py apollo` (Apollo search
     URLs built from the profile, or `--url` from your Apollo account), `python <SCRIPTS>/lead_sources.py leads` (Apollo-style filters, no
     account), `python <SCRIPTS>/lead_sources.py people` (LinkedIn profile search), `python <SCRIPTS>/lead_sources.py employees --company <LinkedIn company URL>`.
     Add `--add --verify` to save them with verified emails. These need a stronger first line — deep-scan first.
   - Companies with a visible need (outbound): `python <SCRIPTS>/lead_sources.py maps --add` (cities from the profile; no website,
     social-only page, low rating, few reviews + phone) and `python <SCRIPTS>/lead_sources.py producthunt --days 7 --add` (new launches).
   - Any other Apify actor: `python <SCRIPTS>/lead_sources.py actor <user/actor> --input in.json`.
     Spend is capped by `APIFY_MAX_USD` (default $1/run) and `APIFY_MAX_RUNS`; tell the user what ran and the counts
     (`sources_run`, `by_source`, `kept_by_source`).
   - With a Bright Data key: `python <SCRIPTS>/intent_scan.py --serp --lookback 7 --max-calls 10 [--country in] --save hunt.json`
     (`--list-queries` shows the default X-ray queries; add your own with `--query '...'`, repeatable).
   - Without a key: search yourself (your web tool, or ask the user to paste posts) for queries like those in
     `references/queries.md`, save posts one per line or as JSON lines (`url`, `text`, `author`) and run
     `python <SCRIPTS>/intent_scan.py --file posts.jsonl --save hunt.json`.
   - One post: `python <SCRIPTS>/intent_scan.py --text "..."`.
   The scanner skips posts seen in earlier runs and rejects sellers, job seekers and job ads for free.
   LinkedIn results include the author's name, headline and profile URL — keep them for step 6. A candidate with
   `contact_in_post` already has an email/phone from the post: use it, don't pay a finder for it.
3. **Judge every candidate** with `references/intent-rubric.md`. For each, decide: buyer / seller /
   job_seeker / other, services wanted, urgency, budget (only if stated), location/timezone (only if stated
   or obvious), and an **exact quote** from the post that proves intent. Discard anything below confidence 0.6.
4. **Score buyers**: write their signals to a JSON file and run
   `python <SCRIPTS>/lead_scorer.py --mode agency signals.json` (fields: `intent_confidence`, `urgency`,
   `posted_days_ago`, `comments`, `budget_stated`, `services_requested`, `services_offered`, `email_status`,
   `sources_count`).
5. **Add to the pipeline** (one per buyer):
   `python <SCRIPTS>/pipeline.py add --url <their site or post URL> --name "<name/company>" --source hunt:<query-id> --services web,seo`
   `python <SCRIPTS>/pipeline.py score <slug> <score>` · `python <SCRIPTS>/pipeline.py note <slug> "Post: <url> — quote: '<exact quote>'"`
6. **Deep-scan the top buyers** (best 5-10, freshest first):
   `python <SCRIPTS>/prospect_scan.py <their site or domain> --post-text "<post>" --post-url <url> [--first X --last Y] --source hunt:<query-id>`
   → `prospects/<slug>/DOSSIER.md` with the audit, people, the best email (finders skipped when the post or site
   already has one), web research and ranked hooks; the prospect and contact go into the pipeline. No website?
   `python <SCRIPTS>/find_email.py --text "<post text>"` and record with `python <SCRIPTS>/pipeline.py contact ...`.
   No verified email? Suggest the user reply publicly under the post or DM from their own account — give
   them a 2-line message. Never post or DM on their behalf.
7. **Report**: a table — buyer, platform, what they need, exact quote, posted, score, contact status, next step.
   Respond to fresh asks (under 48 h) the same day: an email if there is a verified address, otherwise a
   2-line public reply or DM for the user to post from their own account.

## Rules
- The quote must be copied exactly from the post. No quote = not a buyer.
- Agencies advertising, freelancers offering services, "#hiring" job posts and job seekers are never buyers.
- Respect each platform's terms: only public posts, no scraping behind logins, no automated messaging.
- Paid search calls are capped by `--max-calls`; tell the user how many calls a run used.
- Speed beats polish on intent leads: most asks get answered within a day or two by someone.
