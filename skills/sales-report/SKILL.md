# Pipeline Report

You turn the pipeline into decisions: what to do today, this week, and what to stop doing.

## Before you start

1. **Scripts.** `<SCRIPTS>` is the `scripts/` folder of the `sales` skill (`../sales/scripts/` next to this skill's
   folder). Run them with `python` (Windows) or `python3` (macOS/Linux). Each prints one JSON object — treat it as
   evidence to check, not as truth.
2. **The seller.** Read `SELLER-PROFILE.json` if it exists (`python <SCRIPTS>/seller_profile.py show`). If it doesn't,
   carry on with what the user told you and suggest `sales-setup` at the end — don't block urgent work on it.
3. **The prospect.** Everything about one prospect lives in `prospects/<slug>/` — slug = their domain (`acme.com`), or
   `name@platform` (`anita-desai@linkedin`) for a lead without a website. `python <SCRIPTS>/pipeline.py find <email|name|domain>`
   finds it. Never use one prospect's facts for another.
4. **The pipeline.** `~/.ai-sales-team/pipeline.db` is shared by every agent and session. Before you finish, write
   what you learned (stage, note, next action, attached file) — the next agent only sees what the pipeline shows.
5. **Web access.** Use your agent's own fetch/search first; otherwise `python <SCRIPTS>/fetch_page.py <url> ...` and
   `python <SCRIPTS>/web_search.py "<query>"`; with `APIFY_TOKEN`, `python <SCRIPTS>/lead_sources.py`. If you can't fetch
   something, write "Not found".
6. **Facts only.** Never invent people, titles, emails, connections, results, prices or metrics — one invented detail
   in a cold email destroys trust and can break consumer-protection law. Unknown = "Not found"; a guessed email =
   `pattern-guessed — verify before sending`; missing proof = a visible `[ADD REAL CUSTOMER RESULT]`.

## Steps

1. Get the numbers: `python <SCRIPTS>/pipeline.py report` (funnel, conversion, activity, grades, stale, due today, by source, top 10),
   `python <SCRIPTS>/pipeline.py list` and `python <SCRIPTS>/pipeline.py today`; upcoming meetings with `python <SCRIPTS>/meeting.py list`.
2. Fill in from files: for prospects in `prospects/*/` not yet in the pipeline, read their files and add them
   (`python <SCRIPTS>/pipeline.py add ...`, `python <SCRIPTS>/pipeline.py score ...`) so the report is complete.
3. **What works:** `python <SCRIPTS>/learn.py report` — reply, positive-reply and meeting rates by source, query, platform, hook, subject
   A/B, reply step, quality score and country, with recommendations; `python <SCRIPTS>/learn.py report --apply` writes the query weights
   so the next `serp.py watch/hunt` runs the winners first and skips queries that never produced a positive reply.
   Analyse (`references/playbook.md`): pipeline health, stuck deals and why, which sources/queries produce
   replies and meetings (`by_source`), which sequence step gets replies (`python <SCRIPTS>/outreach.py queue` statuses), score
   distribution, gaps (e.g. no verified contacts, sequences not approved, inbox not connected), and the
   **forecast** (`forecast`: open, weighted and won value per currency from `python <SCRIPTS>/pipeline.py value`). Missing values on
   meeting/proposal deals are a gap to fix.
4. Write `SALES-REPORT.md` (`references/output-format.md`): summary, funnel table, top prospects, stale deals,
   source performance, action plan (today / this week / this month) with one concrete action per prospect.
5. Offer `sales-report-pdf` for a shareable version.
