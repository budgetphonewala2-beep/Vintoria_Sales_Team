# Company Research & Firmographics

You produce sourced, structured intelligence on one company. Every claim has a source page or
"Not found".

## Before you start

1. **Scripts.** `<SCRIPTS>` is the `scripts/` folder of the `sales` skill (`../sales/scripts/` next to this skill's
   folder). Run them with `python` (Windows) or `python3` (macOS/Linux). Each prints one JSON object — treat it as
   evidence to check, not as truth.
2. **The seller.** Read `SELLER-PROFILE.json` if it exists (`python <SCRIPTS>/seller_profile.py show`). If it doesn't,
   carry on with what the user told you and suggest `sales-setup` at the end — don't block urgent work on it.
3. **The prospect.** Everything about one prospect lives in `prospects/<slug>/` — slug = their domain (`acme.com`), or
   `name@platform` (`anita-desai@linkedin`) for a lead without a website. `python <SCRIPTS>/pipeline.py find <email|name|domain>`
   finds it. Never use one prospect's facts for another.
4. **The pipeline.** `~/.ai-sales-team/pipeline.db` is shared by every agent and session. Before you finish, write
   what you learned (stage, note, next action, attached file) — the next agent only sees what the pipeline shows.
5. **Web access.** Use your agent's own fetch/search first; otherwise `python <SCRIPTS>/fetch_page.py <url> ...` and
   `python <SCRIPTS>/web_search.py "<query>"`; with `APIFY_TOKEN`, `python <SCRIPTS>/lead_sources.py`. If you can't fetch
   something, write "Not found".
6. **Facts only.** Every fact you write must trace to a script output, a page saved with `fetch_page.py --save`, the
   prospect's own words or the seller's profile — never to memory or to a document you wrote yourself. Never invent
   people, titles, emails, connections, results, prices or metrics: one invented detail in a cold email destroys trust
   and can break consumer-protection law. Unknown = "Not found"; a guessed email = `pattern-guessed — verify before
   sending`; missing proof = a visible `[ADD REAL CUSTOMER RESULT]`. Never say something was sent, booked, verified or
   scanned unless a script's output says so. The guards: `../sales/references/truth-rules.md`.

## Steps

1. Start with the deep scan: `python <SCRIPTS>/prospect_scan.py <url> [--name "<company>"] [--city <city>]` (site audit, company analysis,
   people, email, web research → `DOSSIER.md`). Then fetch what it missed — about, team, careers, services,
   blog/news, case studies — with your web tool or `python <SCRIPTS>/fetch_page.py <url1> <url2> ...`.
2. The web research inside the scan (`python <SCRIPTS>/lead_sources.py research <domain> --name "<company>"` on its own) covers mentions,
   reviews, complaints, news, LinkedIn, founder, social, directories, hiring, ads and competitors and saves
   `prospects/<slug>/WEB-RESEARCH.json` (needs `APIFY_TOKEN` or `BRIGHTDATA_API_KEY`; otherwise use your own
   search tool). Snippets are leads — open the page before stating a fact from it.
3. Cover the 8 dimensions in `references/playbook.md`. Adapt to the business type: for a local business or
   SMB focus on owner, locations, reviews, website quality and marketing activity; for SaaS on product,
   pricing, team growth; for e-commerce on catalogue, platform, channels.
4. Save every page you rely on as evidence: `python <SCRIPTS>/fetch_page.py <url> --save prospects/<slug>/sources`
   (search snippets alone are leads, not facts). Write `prospects/<slug>/COMPANY-RESEARCH.md` using `references/output-format.md`, with a source for each fact,
   ending with **"Why now"** (the trigger: their post, a launch, hiring, bad reviews, an outdated site) and the
   **3 best hooks** for outreach.
   Then `python <SCRIPTS>/claim_check.py --draft prospects/<slug>/COMPANY-RESEARCH.md --prospect <slug>` and fix every
   unsupported line (your own document is never evidence for itself or for later emails).
5. Record: `python <SCRIPTS>/pipeline.py add --url <url> --name "<company>" --stage researched` and
   `python <SCRIPTS>/pipeline.py attach <slug> prospects/<slug>/COMPANY-RESEARCH.md --kind research`; add named leaders with
   `python <SCRIPTS>/pipeline.py contact <slug> --name ... --title ... --source website`.
