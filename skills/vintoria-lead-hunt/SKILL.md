# Vintoria Lead Hunt — find people asking for what we sell

Intent beats cold lists: someone who wrote "need a website for my clinic" this week is worth fifty cold contacts.
You find those posts, separate real buyers from noise, and put them in the pipeline before anyone else answers.

## Before you start

1. **Scripts.** `<SCRIPTS>` is the engine folder `../vintoria-sales/scripts/` (next to this skill's folder), grouped by
   job: `core/` (pipeline, seller profile), `leads/`, `research/`, `outreach/`, `replies/`, `ops/`. Run them with
   `python` (Windows) or `python3` (macOS/Linux). Each prints one JSON object — evidence to check, not truth.
2. **Vintoria's profile.** Run `python <SCRIPTS>/core/seller_profile.py check`. Queries, emails and prices are built
   from `SELLER-PROFILE.json`; if it isn't `Ready.`, run `vintoria-setup` first (in a hurry: ask only the missing required
   questions in one message and save them with `seller_profile.py set`).
3. **What Vintoria sells.** 270 services in 12 disciplines — `../vintoria-sales/references/service-catalog.md`. Name a
   service exactly as the catalog does (`192 Shopify Development`), never invent one, and never quote a price, discount or
   date that isn't in the profile (`../vintoria-sales/references/pricing-policy.md`): use `[PRICE TO CONFIRM]`.
4. **The prospect.** Everything about one prospect lives in `prospects/<slug>/` — slug = their domain (`acme.com`), or
   `name@platform` (`anita-desai@linkedin`) without a website. `python <SCRIPTS>/core/pipeline.py find <email|name|domain>`
   finds it. Never use one prospect's facts for another.
5. **The pipeline.** `~/.ai-sales-team/pipeline.db` is shared by every agent and session. Before you finish, record what
   you learned (stage, note, next action, attached file) — the next agent only sees what the pipeline shows.
6. **Web access.** Your agent's own fetch/search first; otherwise `python <SCRIPTS>/research/fetch_page.py <url> ...` and
   `python <SCRIPTS>/research/web_search.py "<query>"`; with `APIFY_TOKEN`, `python <SCRIPTS>/leads/lead_sources.py`. If you
   can't fetch something, write "Not found".
7. **Facts only.** Every fact traces to a script output, a page saved with `fetch_page.py --save`, the prospect's own
   words, the catalog or the profile — never to memory or to a document you wrote yourself. One invented client, number or
   promise in a cold email destroys trust and can break consumer-protection law. Unknown = "Not found"; a guessed email =
   `pattern-guessed — verify before sending`; missing proof = `[ADD REAL CUSTOMER RESULT]`. Never say something was sent,
   booked, verified or scanned unless a script's output says so. Guards: `../vintoria-sales/references/truth-rules.md`.

## Steps

1. **Aim.** Read `OFFER.md` (the lanes and their entry services) and `python <SCRIPTS>/core/seller_profile.py show`. Hunt one lane at a time — its
   services decide the queries. Map catalog disciplines to engine service codes:
   | Discipline | Codes | Discipline | Codes |
   |---|---|---|---|
   | 02 Web, 03 SaaS | `web`, `software` | 07 AI Development | `ai` |
   | 04 Mobile | `app` | 08 Business Automation | `automation` |
   | 05 UI/UX, 06 Branding | `design` | 09 Backend & Cloud, 01 Strategy | `software` |
   | 10 E-Commerce | `ecommerce` | 11 Marketing & SEO, 12 Growth | `seo`, `marketing` |
   Preview the queries: `python <SCRIPTS>/leads/query_library.py --services ai,automation` (formula and sources: `references/queries.md`).
2. **Collect leads** with what the user has:
   | They have | Run | Gives |
   |---|---|---|
   | `BRIGHTDATA_API_KEY` + `BRIGHTDATA_ZONE` | **`python <SCRIPTS>/leads/serp.py watch`** — newest posts since the last watch, never-seen only; or `python <SCRIPTS>/leads/serp.py hunt --hours 24` / `--days 7` (`python <SCRIPTS>/leads/serp.py providers` shows the cost) | **main source**: Google X-ray across LinkedIn posts, Reddit, Quora, X, FB groups, Indie Hackers, Upwork in the profile's countries, newest first, with exact post times |
   | `APIFY_TOKEN` | `python <SCRIPTS>/leads/lead_sources.py hunt --posted week --max 30 --save hunt.json` | LinkedIn post search, Hacker News, Reddit, X |
   | `APOLLO_API_KEY` or an Apollo connector | `python <SCRIPTS>/leads/lead_sources.py apollo-api --max 100` (or the connector with the profile's titles, countries, size, niches) | decision-maker lists (no intent) |
   | a local niche (clinics, restaurants, coaching) | `python <SCRIPTS>/leads/lead_sources.py maps --add` | businesses with no site / poor reviews + phone — strong in Indian cities |
   | nothing | `python <SCRIPTS>/leads/lead_sources.py hackernews`, `python <SCRIPTS>/leads/lead_sources.py reddit` (free); otherwise run `python <SCRIPTS>/leads/query_library.py` queries in your own search, save posts as JSON lines (`url`, `text`, `author`) and `python <SCRIPTS>/leads/intent_scan.py --file posts.jsonl --save hunt.json` | |
   Before a paid run, tell the user the ceiling (`APIFY_MAX_USD` × `APIFY_MAX_RUNS`, default $1 × 8); after it, what ran
   (`sources_run`, `by_source`, `kept_by_source`, `excluded_market`). A candidate with `contact_in_post` already has an
   email/phone — use it, don't pay a finder.
   **Freshness wins the client.** Work newest first (`age_hours`): under 6 h → judge, scan and answer this session;
   under 48 h → today; older than a week only if nobody has replied under it. Mark what you judged: `python <SCRIPTS>/leads/serp.py judged <url> ...`.
3. **Judge every candidate** with `references/intent-rubric.md`: buyer / seller / job_seeker / other, services wanted
   (as catalog IDs where clear — "AI chatbot for my clinic" → `123 AI Chatbot Development`), urgency, budget (only if
   stated), location, and an **exact quote** that proves intent. Drop anything under confidence 0.6.
4. **Score buyers:** `python <SCRIPTS>/leads/lead_scorer.py --mode agency signals.json` (`intent_confidence`, `urgency`, `posted_days_ago`, `comments`,
   `budget_stated`, `services_requested`, `services_offered`, `email_status`, `sources_count`). Leave unknown fields out —
   unknowns score neutral; writing 0 would claim "posted today, no competition".
5. **Add to the pipeline** — their own website if the post or profile names one, else the post URL (becomes
   `name@platform`, so leads never merge):
   `python <SCRIPTS>/core/pipeline.py add --url <site or post URL> --name "<person or company>" --source serp:<query id> --quote "<exact words>" --post-text "<the post>"`
   (the quote is checked word for word; a paraphrase is refused), then `python <SCRIPTS>/core/pipeline.py score <slug> <score>`.
   `python <SCRIPTS>/core/pipeline.py contact` takes the person's **profile** URL as `--linkedin`, never the post URL.
6. **Deep research on every buyer kept**, freshest first — one command per post:
   `python <SCRIPTS>/leads/post_lead.py --post-url <url> --post-text "<the post>" --author "<name>" --author-url <profile> --headline "<headline>" --source serp:<query-id> --quote "<exact words>"`
   (or all kept buyers: `python <SCRIPTS>/leads/post_lead.py --hunt hunt.json --only <url>,<url> --top 20`). It reads the post (email, phone, site —
   free), the author's profile, finds the company site (**never guessed**), runs the full deep scan and writes
   `prospects/<slug>/DOSSIER.md`. No verified email → give the user a 2-line public reply or DM to send themselves.
7. **Report:** buyer, platform, what they need (+ catalog service), exact quote, posted, score, contact status, next step.
   Fresh asks (< 48 h) get answered today — email if verified, otherwise the user's own public reply.

## Rules
- The quote is copied exactly from the post. No quote = not a buyer.
- Agencies, freelancers offering services, "#hiring" job posts and job seekers are never buyers.
- Only public posts; no scraping behind logins; never post, comment or DM for the user.
- Speed beats polish on intent leads: most asks get answered within a day or two.
