# Truth rules — every sentence must trace to evidence

One invented client, number, tool or promise destroys the deal and can break consumer-protection law. There is no
script to catch you, so the self-check below is the guard. It applies to every email, dossier, proposal and call note.

## What counts as evidence

| Evidence (trusted) | Tier | Not evidence |
|---|---|---|
| A page you opened in this session (their site, their post, a review, a news article), noted with URL and date | page | What you "remember" about a company or industry |
| The prospect's own words: their post, their replies (`THREAD.md`) | prospect | A search-result snippet on its own — open the page first |
| Facts you observed on their site yourself (no viewport tag, copyright 2019, no contact form) | audit | A guess about traffic, revenue, team size or tools |
| The Vintoria catalog (`service-catalog.md`, `services-*.md`): service names, IDs, scope | catalog | A service, price, package, SLA or timeline the catalog doesn't contain — it has no prices at all |
| `SELLER-PROFILE.md`: case studies, clients, years, prices, delivery, guarantees | profile | Results, clients or guarantees that aren't in the profile |
| Today's date | calendar | Holidays or deadlines you didn't check |

Documents you wrote yourself (`DOSSIER.md`, research, drafts, proposals, meeting notes) are **never** evidence for a new
claim — go back to the page or the post they came from.

## Where agents usually invent — and the rule

| Temptation | Rule |
|---|---|
| A sentence with no source ("your competitors already do this") | Every declarative sentence needs a source; greetings, sign-offs, the opt-out, offers ("happy to send…") and questions are exempt |
| Flipping a fact ("your site **has** a viewport tag") | Re-read the evidence sentence; a claim must not contradict it |
| An invented client, tool, person or place ("we rebuilt Sephora's store", "your WordPress site") | Every name, brand and place in a claim must appear in the same source that supports it |
| A wrong or invented number | Every number must appear in one single source, same unit |
| A misquote | Text in quotation marks is copied word for word from the post or page |
| Industry "facts" ("most of your visitors…", "studies show…") | Only with a source that says it; otherwise cut it |
| Promises ("page one in 30 days", "double your sales") | Only guarantees written in the profile |
| A snippet about a different company with a similar name | Use research only when it clearly names this prospect |
| An email presented as real | Only `verified` / `published` addresses are called real; guesses are labelled `pattern-guessed — verify before sending` |
| The wrong name in the greeting | Check the name against the contact in `PIPELINE.md` |
| Saying something was sent, booked, verified or scanned | Only when the user confirmed it or a tool showed it; otherwise say what is still to do |
| Prices, timelines, scope | Only from the profile; otherwise `[PRICE TO CONFIRM]` / `[TO CONFIRM]`; never "agencies usually charge…" |
| A service Vintoria doesn't sell | Name services exactly as the catalog does (ID + name); a need outside the 270 is said plainly, with the closest covered service |

## Writing when you don't know

| Situation | Write |
|---|---|
| Unknown fact in research | `Not found` |
| Unknown fact in an email | leave it out |
| A likely consequence | hedge it: "so phone visitors may see the desktop layout" |
| Missing proof | a visible `[ADD REAL CUSTOMER RESULT]` |
| Missing price or date | `[PRICE TO CONFIRM]`, `[TO CONFIRM: timeline]` |
| Two sources disagree | say so; prefer the page the prospect controls, then their own words |

## The self-check (run it before anyone sees a draft)

1. Go through every declarative sentence and name its source (page + date, their post, the audit, the catalog, the profile).
2. A sentence with no source: delete it or turn it into a question.
3. Every name, brand and place appears in that same source; every number appears in one source; quotes are verbatim.
4. No price, date, result or guarantee that isn't in the profile.
5. Only the approved markers (`[ADD REAL CUSTOMER RESULT]`, `[PRICE TO CONFIRM]`, `[TO CONFIRM: …]`) remain, and the
   user is told each one must be filled before sending.

If a draft fails, fix the draft — never lower the standard. Tell the user in one line: "Self-check: N claims, all sourced."
